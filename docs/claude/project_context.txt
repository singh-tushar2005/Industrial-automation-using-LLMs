Industrial Automation using LLMs
Project Context Document

PROJECT OVERVIEW

This project focuses on building a semantic transformation pipeline for migrating legacy industrial automation systems from IEC 61131-3 to IEC 61499.

The long-term goal is to create a transformation-oriented industrial semantic analysis platform capable of:

parsing IEC61131-3 Structured Text
generating AST representations
performing semantic analysis
understanding industrial control behavior
extracting semantic relationships
generating semantic graphs
producing transformation-oriented IR
eventually enabling IEC61499 generation

The project intentionally evolves in layered compiler-style stages.

AST LAYER

The AST layer defines structured program representations.

Important:

AST does NOT parse code itself
parser creates AST objects
AST remains parser-independent

Example nodes:

ProgramNode
BlockNode
IfStatementNode
AssignmentNode
BinaryExpressionNode
LogicalExpressionNode
VariableNode
BooleanNode
NumberNode
PARSER LAYER

The parser:

parses IEC61131-3 Structured Text
uses pyparsing
recognizes grammar structures
constructs AST node objects

Current capabilities:

assignments
logical expressions
arithmetic expressions

Planned:

SEMANTIC LAYER

VISITOR

Provides reusable recursive AST traversal infrastructure.

Important:

visitor is traversal infrastructure
semantic systems reuse traversal logic
visitor is NOT business logic

SYMBOL TABLE

Acts as semantic memory.

Stores:

variable names
semantic types
future semantic metadata

Example:
Motor → BOOL
Temp → NUMBER

TYPE CHECKER

Performs semantic correctness validation.

Responsibilities:

assignment compatibility
expression validation
type legality

The type checker:

reuses visitor traversal
queries symbol table
validates semantic correctness
