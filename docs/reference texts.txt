IEC MIGRATION LLM PROJECT — REFERENCE ROADMAP
=============================================

GOAL:
Build foundational knowledge for developing an AI-assisted IEC 61131-3 → IEC 61499 migration system using:
- parsing
- ASTs
- semantic analysis
- LLM orchestration
- verification
- transformation pipelines

IMPORTANT:
Follow this order strictly.
Do NOT jump immediately into advanced LLM papers or fine-tuning.


======================================================================
STAGE 1 — COMPILER & PARSER FOUNDATIONS (HIGHEST PRIORITY)
======================================================================

WHY:
Your project is fundamentally a compiler/transformation system.
Before AI, you must understand:
- parsing
- ASTs
- semantic representations
- IRs
- interpreters

----------------------
